- **契约标识**：`CONSENT-GOV-v1.0`
- **版本号**：`v1.0`
- **生效日期**：2026-09-18
- **责任人**：数据负责人

---

## 1. 伦理合规与知情同意制度

视频数据包含面部与体态等直接或间接可识别信息。本项目依据《个人信息保护法》的“目的明确、最小必要、告知同意、分类保护”原则制定项目内部准入门槛：

1. **唯一合法性来源**：每一段受试视频必须绑定唯一且有效的 `consent_id`，禁止使用网络爬取、测试集留存或未成年人数据。
2. **目的特定化**：数据严格仅用于“本科毕业设计单人深蹲评估原型研究”，不得用于人脸身份识别、跨视频 Re-ID 追踪、商业用途或医疗诊断。
3. **独立展示授权**：“论文插图使用与答辩现场展示”作为知情同意书中的**独立可选项**，默认未勾选。未取得独立授权的视频，即使参与者签署了基础处理同意，也绝不允许导出截图用于答辩展示。

## 2. 数据分级存储体系（S1–S4）

| 级别 | 定义与范畴 | 存储与访问策略 | Git 版本控制策略 |
|---|---|---|---|
| **S1：原始敏感数据** | 原始录制视频、实名映射表、带人脸的未处理截帧 | 本地加密存储；仅数据管理员有解密权限 | **严格禁止入库（.gitignore）** |
| **S2：受控派生数据** | 提取的 33 关键点坐标、时序阶段日志、骨架叠加视频 | 采用假名化代号（如 `subj_001`）；项目内部分析 | **禁止公开入库（.gitignore）** |
| **S3：展示证据** | 获得独立展示授权的面部遮蔽截帧、统计图表 | 答辩前由指导老师/负责人进行合规复核 | 受控提交至展示归档目录 |
| **S4：公开工程规范** | 规则卡集、机位配置文件、基线清单、评测脚本 | 公开 | 正常版本库管理 |

## 3. 算法层凭证解耦与生命周期处置

1. **算法层隔离机制（Permit-based Access）**：
   - 算法分析模块不直接接触受试者真名或原始同意书；
   - 准入层核验合格后，仅为视频样本颁发 `processing_permit_id` 和 `permit_snapshot_version`；
   - 一旦受试者主张撤销同意，准入层吊销许可凭据，算法链路自动熔断（`CONSENT_BLOCKED`）。
2. **到期处置机制（`retention_until: 2026-12-31`）**：
   - 项目在答辩归档完成后（2026年12月31日），启动全面处置流程；
   - 依据索引全面物理擦除 S1 原始视频、S2 派生数据及中间计算缓存；
   - 仅留存不含个人信息的脱敏销毁审计记录备查。
