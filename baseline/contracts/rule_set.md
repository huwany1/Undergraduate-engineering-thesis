## 1. 规则设计与证据链准则

本项目首版所有动作评估提示必须满足**强因果、可解释、有证据**三项要求。禁止使用“尽量蹲深”、“适当直立”等模糊用语。所有特征提取均严格约束在 2D 屏幕像素归一化空间中。

首版仅冻结三条核心规则：

### 规则一：`R-CYCLE-001` 完整动作周期状态机
- **目标**：判定动作是否走完一次标准深蹲生命周期。
- **状态序列**：`STANDING`（站立准备） $\to$ `DESCENDING`（下蹲离心） $\to$ `BOTTOM`（最低停留点） $\to$ `ASCENDING`（起身向心） $\to$ `STANDING`（还原直立）。
- **抗抖动机制**：双阈值迟滞（Hysteresis）比较 + 状态最小停留帧数门槛（$\ge 4$ 帧），单帧抖动不触发状态跃迁。
- **输出**：只有当 5 个阶段无缺失、无倒流依序完成时，输出 `COMPLETE_REP` 并执行计数加一；否则输出 `INCOMPLETE_REP`，计数不变。

### 规则二：`R-DEPTH-001` 2D 屏幕空间下蹲深度代理
- **目标**：评估最低点阶段臀部下沉幅度是否充分。
- **几何特征**：归一化屏幕空间下选定侧髋关节与膝关节的纵向相对差值：
  $$\Delta y = y_{\text{knee}} - y_{\text{hip}}$$
- **工程阈值**：以校准集标定值为基准，标称阈值为 $\Delta y \ge 0.0$（即最低点髋部垂直位置平齐或略低于膝部）。
- **输出**：未达到阈值时触发 `INSUFFICIENT_DEPTH`（严重度：WARNING），提示：“下蹲深度未达标：臀部未下移至与膝关节持平水平”。达到时输出 `RULE_NOT_TRIGGERED`。

### 规则三：`R-LEAN-001` 2D 屏幕空间躯干前倾角代理
- **目标**：评估动作过程中躯干与竖直方向的偏角。
- **几何特征**：在 2D 画面中计算肩部与髋部连线相对于垂直铅垂线的夹角 $\theta_{\text{lean}}$：
  $$\theta_{\text{lean}} = \left| \arctan2(x_{\text{shoulder}} - x_{\text{hip}},\, y_{\text{hip}} - y_{\text{shoulder}}) \times \frac{180^\circ}{\pi} \right|$$
- **工程阈值**：固定侧视标定阈值标称为 $45^\circ$。
- **输出**：在下蹲或最低点阶段若 $\theta_{\text{lean}} > 45^\circ$，触发 `EXCESSIVE_TORSO_LEAN`（严重度：WARNING），提示：“躯干前倾幅度偏大：请收紧核心，保持胸部稳定”。

## 2. 结果聚合策略（`AGG-STRICT-GATED-v1.0`）

1. **门控熔断覆盖**：若发生未入镜、出框、遮挡或动作未走完，总体状态强制标记为 `NOT_EVALUATED`，屏蔽任何动作质量判断。
2. **多规则并行输出**：一次完整深蹲可同时触发 `INSUFFICIENT_DEPTH` 和 `EXCESSIVE_TORSO_LEAN`，系统按严重度降序、规则编号升序稳定排列输出。
3. **未触发语义**：单条规则输出 `RULE_NOT_TRIGGERED` 仅代表当前规则未命中，不代表动作完全符合生物力学最优解。
